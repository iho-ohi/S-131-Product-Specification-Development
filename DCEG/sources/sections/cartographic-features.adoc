== Cartographic Features

=== Introduction

This product specification uses the *TextPlacement* cartographic features derived from S-101. The structure of the feature and its usage are the
same as in S-101 but the feature specification in S-131 omits elements which are not relevant to marine harbour infrastructure, for example, ‘light characteristic’
is omitted as a listed value for the attribute _textType_.
